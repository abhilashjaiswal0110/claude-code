## 🎯 Learning Paths

### Path 1: Complete Beginner
1. Read [SETUP_DEMO.md](./SETUP_DEMO.md) and install everything
2. Read [GETTING_STARTED.md](./GETTING_STARTED.md) for overview
3. Try examples from [EXAMPLES.md](./EXAMPLES.md)
4. Explore plugins in [PLUGIN_GUIDE.md](./PLUGIN_GUIDE.md)
5. Use [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) as needed

**Estimated time:** 2-3 hours

---

### Path 2: Quick Start
1. Skim [SETUP_DEMO.md](./SETUP_DEMO.md) for installation
2. Install Node.js and Claude Code
3. Jump to [EXAMPLES.md](./EXAMPLES.md) and try examples
4. Reference [PLUGIN_GUIDE.md](./PLUGIN_GUIDE.md) for specific plugins
5. Use [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) if issues arise

**Estimated time:** 1 hour

---

### Path 3: Plugin Developer
1. Read [GETTING_STARTED.md](./GETTING_STARTED.md) for context
2. Study plugin structure in [PLUGIN_GUIDE.md](./PLUGIN_GUIDE.md)
3. Follow plugin development examples in [EXAMPLES.md](./EXAMPLES.md)
4. Use Plugin Dev plugin: `/plugin-dev:create-plugin`
5. Reference [TROUBLESHOOTING.md](./TROUBLESHOOTING.md) for debugging

**Estimated time:** 2-4 hours

---

### Path 4: Team Lead / Manager
1. Skim [GETTING_STARTED.md](./GETTING_STARTED.md) for overview
2. Read [PLUGIN_GUIDE.md](./PLUGIN_GUIDE.md) to understand capabilities
3. Review [EXAMPLES.md](./EXAMPLES.md) for team workflows
4. Plan rollout using [SETUP_DEMO.md](./SETUP_DEMO.md)
5. Prepare team resources from [TROUBLESHOOTING.md](./TROUBLESHOOTING.md)

**Estimated time:** 1-2 hours
