# Cloud Engineering Skill Framework (Sample)

## Levels

### Junior (0-2 years)
- Basic understanding of cloud services (compute, storage, networking)
- Can deploy simple applications to cloud
- Familiar with one cloud platform (AWS/Azure/GCP)
- Basic scripting (Bash, Python)
- Understanding of CI/CD concepts

### Mid-Level (2-5 years)
- Multi-cloud experience
- Infrastructure as Code (Terraform, CloudFormation)
- Container orchestration (Kubernetes)
- Monitoring and observability tools
- Security best practices and IAM
- Cost optimization strategies

### Senior (5-8 years)
- Architecture design and review
- Multi-region and disaster recovery
- Performance optimization at scale
- Mentoring and knowledge transfer
- Vendor management and evaluation
- Compliance and governance frameworks

### Principal/Staff (8+ years)
- Enterprise architecture strategy
- Cloud-native transformation roadmaps
- Industry thought leadership
- Cross-functional stakeholder management
- Innovation and emerging technology evaluation
- Organizational capability building
