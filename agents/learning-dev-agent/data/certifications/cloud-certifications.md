# Cloud Certifications Guide (Sample)

## AWS Certifications
- **AWS Cloud Practitioner** - Foundational, 6 months experience
- **AWS Solutions Architect Associate** - Associate, 1 year experience
- **AWS Solutions Architect Professional** - Professional, 2+ years
- **AWS DevOps Engineer Professional** - Professional, 2+ years
- **AWS Security Specialty** - Specialty, 2+ years security experience

## Azure Certifications
- **AZ-900: Azure Fundamentals** - Foundational
- **AZ-104: Azure Administrator** - Associate
- **AZ-305: Azure Solutions Architect Expert** - Expert
- **AZ-400: DevOps Engineer Expert** - Expert
- **SC-100: Cybersecurity Architect Expert** - Expert

## Google Cloud Certifications
- **Cloud Digital Leader** - Foundational
- **Associate Cloud Engineer** - Associate
- **Professional Cloud Architect** - Professional
- **Professional Cloud DevOps Engineer** - Professional

## Kubernetes
- **CKA: Certified Kubernetes Administrator**
- **CKAD: Certified Kubernetes Application Developer**
- **CKS: Certified Kubernetes Security Specialist**
